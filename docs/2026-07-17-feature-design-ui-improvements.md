# 열 이동 배달 추적소 기능·디자인·UI 개선 기록

- 작성일: 2026-07-17
- 대상: `feature/educational-mvp`
- 검토 범위: 안내 활동, 사건 진행 단계, 열 이동 작업대, 그래프·표, 모바일·키보드·접근성
- 검토 방법: 로컬 렌더링 화면을 Playwright Chromium으로 1440×1000, iPhone 13, 320×720에서 확인하고 전체 화면 캡처와 주요 학습 흐름을 비교함

## 1. 첫인상

- 이 앱은 **과학 개념을 조심스럽게 다루는 단계형 학습 도구**로 보입니다.
- 굵은 남색 선과 높은 대비는 또렷하지만, 안내·보조 버튼·학습 자료가 비슷한 시각적 무게를 가져 학생이 첫 행동을 찾는 속도가 느립니다.
- 시선이 먼저 가는 곳은 **브랜드와 상단 도구**, **큰 사건 제목**, **온도 물체와 방향 화살표** 순서입니다. 실제로 가장 먼저 해야 할 선택과 다음 행동은 그 뒤에 있습니다.
- 한 단어로 표현하면 **성실함**입니다. 개념 안전성은 높지만 모바일 학습 리듬은 더 가볍고 선명해질 필요가 있습니다.

## 3. 발견한 문제와 개선 결정

### FINDING-001 · 모바일 열 이동 작업대의 정보 잘림 — 높음

- 증거: iPhone 13 폭에서 양쪽 물체 칸이 지나치게 좁아 `가상 고체 A/B`, 재료 설명이 여러 줄로 갈라지거나 잘립니다.
- 원인: 작은 화면에서도 `물체 → 방향 → 물체`를 한 줄에 유지합니다. 문서 전체는 가로로 넘치지 않아 기존 가로 스크롤 검사로 발견되지 않았습니다.
- 개선: 700px 이하에서는 두 물체와 방향 설명을 세로 순서로 배치하고 각 물체가 전체 폭을 사용하게 합니다.
- 완료 조건: 320px과 390px에서 두 물체 이름·온도·재료·방향 설명이 모두 읽히며 내부 잘림과 문서 가로 스크롤이 없습니다.

### FINDING-002 · 첫 화면의 시작 행동이 너무 늦게 나타남 — 높음

- 증거: 모바일에서 상단 도구가 두 줄로 감기고, 네 개의 긴 모형 안내 뒤에 확인 체크와 시작 버튼이 나옵니다.
- 개선: 상단 도구 문구를 짧게 하고 한 줄 도구 레일로 유지합니다. 필수 개념 두 개는 바로 보이고, 자료·안전 설명은 펼쳐 보는 보충 안내로 묶습니다.
- 완료 조건: 필수 개념은 숨기지 않으면서 모바일 전체 높이가 줄고, `첫 사건 시작하기`를 더 빠르게 발견할 수 있습니다.

### FINDING-003 · 현재 단계와 다음 행동의 연결이 약함 — 중간

- 증거: 7개 단계명이 밑줄 텍스트로만 나열되고 모바일에서 두 줄로 분리됩니다. 완료·현재·예정 상태도 구분되지 않습니다.
- 개선: 순서가 있는 단계 탐색으로 바꾸고 `완료`, `현재`, `예정` 상태와 `n/7` 진행 정보를 제공합니다. 현재 단계에는 `aria-current="step"`을 적용합니다.
- 완료 조건: 모바일에서 단계 표시가 한 줄로 탐색 가능하고, 화면 낭독기와 시각 사용자 모두 현재 위치를 알 수 있습니다.

### FINDING-004 · 그래프가 학습 내용보다 큰 면적을 차지함 — 중간

- 증거: 시작 시점 한 점만 열린 상태에서도 그래프가 데스크톱에서 거의 정사각형으로 커져 원자료 표와 이전 단계 버튼을 멀리 밀어냅니다.
- 개선: 그래프 좌표계를 가로형 비율로 바꾸고 데이터 선·눈금·범례를 유지합니다.
- 완료 조건: 그래프 의미와 접근성 이름은 보존하면서 데스크톱과 모바일 모두 세로 길이가 줄어듭니다.

### FINDING-005 · 반응형 회귀 검사가 내부 잘림을 놓침 — 중간

- 증거: 기존 테스트는 문서의 `scrollWidth`만 검사해 컨테이너 내부 글자 잘림을 통과시켰습니다.
- 개선: 320px에서 물체 카드와 방향 설명의 실제 너비, 텍스트 표시, 단계 표시 상태를 검사하는 회귀 테스트를 추가합니다.
- 완료 조건: 모바일 작업대가 다시 한 줄로 압축되면 자동 테스트가 실패합니다.

## 4. 구현 범위

1. `ThermalWorkbench`의 반응형 정보 구조 개선
2. `ModelGuide`의 필수 안내와 보충 안내 구분
3. `AppHeader`의 모바일 도구 레일 간소화
4. `ScenarioFlow`의 완료·현재·예정 단계 표시 및 진행률 접근성 개선
5. `TemperatureChart`의 가로형 좌표계 적용
6. 모바일 내부 잘림과 단계 진행 상태 E2E 회귀 테스트 추가
7. 앱의 `업데이트 내역`에 이번 개선 사항 추가

## 5. 변경하지 않는 범위

- 과학 자료 값, 정답 판정, 전도·대류·복사 분류는 바꾸지 않습니다.
- 학생 점수·계정·저장·센서·외부 API는 추가하지 않습니다.
- 기존 5개 사건의 순서와 핵심 학습 순환은 유지합니다.
- 모바일에서 내용을 감추기 위해 핵심 온도나 알짜 방향 정보를 삭제하지 않습니다.

## 7. 구현·검증 결과

### 구현 파일

- `app/tracker.css`: 700px 이하의 작업대 세로 배치, 44px 도구 버튼, 가로형 그래프 비율, 단계 레일의 잘림 방지와 상태 표현을 추가했습니다.
- `src/components/AppHeader.tsx`: 작은 화면에서 읽기 쉬운 짧은 도구 이름과 보조 접근성 이름을 적용했습니다.
- `src/features/ModelGuide.tsx`: 필수 안내 두 항목을 먼저 보이고 자료·안전 안내는 펼쳐 보는 보충 안내로 정리했습니다.
- `src/features/ScenarioFlow.tsx`: 완료·현재·예정 단계, `aria-current="step"`, 키보드로 접근 가능한 가로 단계 레일을 적용했습니다.
- `src/visualization/ThermalWorkbench.tsx`, `src/visualization/TemperatureChart.tsx`: 모바일 검사 훅을 추가하고 그래프 좌표계를 가로형으로 조정했습니다.
- `src/content/explanations.ts`: `v1.0.1` 업데이트 내역을 기록했습니다.
- `tests/e2e/learning-flow.spec.ts`: 320px·390px 내부 잘림, 44px 터치 타깃, 단계 상태와 목록 기본 여백 회귀 검사를 추가했습니다.

### 남은 의도적 차이

- 320px처럼 매우 좁은 화면에서는 7개 단계 전체를 억지로 줄이지 않고 **가로 단계 레일**로 유지합니다. 현재 단계는 즉시 보이며, 나머지 단계는 좌우로 넘겨 확인할 수 있습니다. 이 레일은 키보드 포커스와 접근성 안내를 지원합니다.
