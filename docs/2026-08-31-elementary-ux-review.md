- 적용 workflow: `elementary-webapp-ux-orchestrator` (`full`)
- 대상: 초등 5~6학년, 초3~4 가드레일
- 주 페르소나: 서윤(10~12세) / 가드레일: 준호(8~10세)

- VoiceOver/TTS 검증: 제외

## 기준선에서 찾은 문제

1. 사건 1에서 방해 카드 `액체·기체의 움직임`을 필수 근거와 함께 고르면 결과의 `까닭`에 오개념이 남을 수 있었습니다(P1).
2. 시간 자료 문장이 비교·분류·화살표 확인을 한 번에 요구했습니다(P2).
3. 320px에서 그래프 제목이 `그래프`로 갈라지고, 단계 레일에 옆으로 밀기 단서가 약했습니다(P2).
4. 전체 완료 화면의 유일한 재시작 CTA가 앞 단계와 달리 강조되지 않았습니다(P2).

## 반영한 개선

| 영역 | 개선 내용 |
| --- | --- |
| 근거 안전성 | `areExactlyRequiredEvidenceSelected`로 필수 ID만 정확히 선택했을 때 기록 버튼을 활성화합니다. 방해 카드가 있으면 선택 개수와 `맞지 않는 카드는 다시 눌러 빼 주세요.`를 표시하고, 결과에서도 필수 근거만 방어적으로 출력합니다. |
| 학습 문장 | `온도 숫자를 먼저 비교해요. 그다음 화살표를 찾아요.`와 `전 단계와 온도를 비교해요. 올라감·내려감·그대로 중 하나를 찾아요.`로 나누고, 체크 라벨을 `온도 변화와 화살표를 확인했어요.`로 짧게 조정했습니다. |
| 행동 순서 | 시간 자료에 `순서: 자료 읽기 → 이 상자 체크 → 다음 단계 열기/자료 추적 마치기`를 표시했습니다. |
| 모바일 UI | 700px 이하 단계 레일에 `옆으로 밀어 다음 단계도 볼 수 있어요.`를 추가하고, 그래프 제목은 한 줄로 고정하며 범위 텍스트를 다음 줄에 배치했습니다. |
| 행동 강조 | 기존 체크 행·조건 충족 CTA·다음 시간 단계 버튼에 더해 근거 기록, 결과 다음 사건, 전체 완료의 재시작 CTA까지 `gi-pulse`를 적용했습니다. `prefers-reduced-motion`에서는 정적 아우라로 대체합니다. |
| 기록 | 업데이트 내역을 `v1.0.5`(2026-08-31)로 갱신했습니다. |
